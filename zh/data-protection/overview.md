# 数据保护

数据保护可防止 AI 交互过程中意外或恶意泄露机密业务信息和个人身份信息 (PII)。

---

## 核心防护能力

### 1. DLP 管理（业务数据丢失防护）
保护提示、上传文件和模型响应中的专有业务资产：
- **API 密钥和凭证**：防止 AWS 密钥、OpenAI 令牌、密码和私有证书泄露。
- **源代码和架构**：检测内部存储库和代码片段。
- **合同和财务**：识别机密协议草案和财务数据。

### 2. PII 编辑（隐私与合规性）
自动检测和屏蔽个人标识符以满足 GDPR、HIPAA 和 CCPA 标准：
- **标识符**：姓名、电子邮件地址、电话号码、国民身份证（SSN、DNI、护照号码）、信用卡。
- **密文模式**：
  - **掩码**：混淆敏感字符串（例如，user@*****.com、****-****-****-1234）。
  - **删除**：完全删除敏感文本。
  - **Tokenize / Hash**：用确定性假名替换敏感数据以进行内部处理。

### 3.语义验证器
通过确定您的 SecureAI 租户是否生成可疑文本来协助安全和法律调查：
- **置信度**：*已验证*、*可能匹配*、*不明确*、*不匹配*。
- **用法**：转到**管理员？数据保护？语义验证器**并粘贴文本片段以分析来源概率。

## 配置和设置

1. **全局设置**：转到**管理员？数据保护** 支持实时扫描输入、输出和文件附件。
2. **模板和自定义规则**：加载区域/行业入门模板或添加自定义正则表达式模式。
3. **模拟模式**：在生产中实施策略之前，先针对示例数据集测试策略。
4. **事件监控**：查看数据保护事件日志下的修订和阻止指标。
