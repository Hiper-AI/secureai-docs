# Dokumentenverarbeitung

Mit SecureAI können Sie verschiedene Dokumenttypen hochladen und verarbeiten, um Ihre persönliche Wissensdatenbank für verbesserte KI-Antworten zu erstellen.

## Unterstützte Dateitypen

### **Dokumentformate**
- **PDF-Dokumente**: Textextraktion und -verarbeitung
- **Word-Dokumente**: DOC-, DOCX-Dateien
- **Textdateien**: Nur-Text und Markdown
- **Strukturierte Daten**: CSV-, JSON-Dateien

### **Dateigrößenbeschränkungen**
- **Maximale Dateigröße**: 10 MB pro Datei
- **Batch-Upload**: Laden Sie mehrere Dateien gleichzeitig hoch
- **Verarbeitungszeit**: Variiert je nach Dateigröße und Komplexität

## Upload-Prozess

### **Schritt 1: Wählen Sie Ihre Wissensdatenbank aus**
- Wählen Sie eine vorhandene Wissensdatenbank oder erstellen Sie eine neue
- Benennen Sie Ihre Wissensdatenbank zur leichteren Identifizierung

### **Schritt 2: Dokumente hochladen**
- **Drag and Drop**: Ziehen Sie Dateien einfach in den Upload-Bereich
- **Dateibrowser**: Klicken Sie hier, um Dateien zu durchsuchen und auszuwählen
- **Stapelauswahl**: Wählen Sie mehrere Dateien gleichzeitig aus
- **Fortschrittsverfolgung**: Sehen Sie den Upload-Fortschritt in Echtzeit

### **Schritt 3: Bearbeitungsstatus**
- **Upload-Bestätigung**: Dateien wurden erfolgreich hochgeladen
- **Verarbeitungsindikator**: Beobachten Sie, wie Dokumente verarbeitet werden

## Was Sie tun können

### **Dokumentenverwaltung**
- **Dokumente hochladen**: Fügen Sie Dateien zu Ihrer Wissensdatenbank hinzu
- **Hochgeladene Dateien anzeigen**: Alle Dokumente in Ihrer Wissensdatenbank anzeigen

### **Wissensbasisorganisation**
- **Mehrere Datenbanken erstellen**: Dokumente nach Thema oder Projekt organisieren
- **Benennen Sie Ihre Datenbanken**: Geben Sie Ihren Wissensdatenbanken aussagekräftige Namen

## Best Practices

### **Dokumentenvorbereitung**
- Verwenden Sie hochwertige, lesbare Dokumente
- Stellen Sie sicher, dass der Text klar und gut formatiert ist
- Entfernen Sie unnötige Formatierungen oder Bilder
- Verwenden Sie beschreibende Dateinamen

### **Organisation**
- Gruppieren Sie verwandte Dokumente in derselben Wissensdatenbank
- Verwenden Sie einheitliche Namenskonventionen
- Erstellen Sie separate Wissensdatenbanken für verschiedene Projekte
- Überprüfen und bereinigen Sie regelmäßig alte Dokumente

### **Tipps hochladen**
- Laden Sie Dokumente aus Effizienzgründen stapelweise hoch
- Überwachen Sie den Verarbeitungsstatus großer Dateien
- Halten Sie die Dateigröße für eine schnellere Verarbeitung unter 10 MB

## Häufige Probleme

| Problem | Lösung |
|-------|----------|
| Datei zu groß | In kleinere Dateien aufteilen oder komprimieren |
| Verarbeitung fehlgeschlagen | Dateiformat prüfen und erneut versuchen |
| Hochladen hängt | Seite aktualisieren und erneut versuchen |

## Erste Schritte

1. **Wissensdatenbank erstellen**: Erstellen Sie zunächst eine neue Wissensdatenbank
2. **Dokumente hochladen**: Fügen Sie Ihre ersten Dokumente hinzu
3. **Auf Verarbeitung warten**: Lassen Sie das System Ihre Dateien verarbeiten
4. **Mit dem Chatten beginnen**: Nutzen Sie Ihre Wissensdatenbank in Gesprächen
