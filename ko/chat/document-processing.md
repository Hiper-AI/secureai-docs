# 문서 처리

SecureAI를 사용하면 다양한 문서 유형을 업로드하고 처리하여 향상된 AI 대응을 위한 개인 지식 베이스를 만들 수 있습니다.

## 지원되는 파일 형식

### **문서 형식**
- **PDF 문서**: 텍스트 추출 및 처리
- **Word 문서**: DOC, DOCX 파일
- **텍스트 파일**: 일반 텍스트 및 마크다운
- **구조화된 데이터**: CSV, JSON 파일

### **파일 크기 제한**
- **최대 파일 크기**: 파일당 10MB
- **일괄 업로드**: 여러 파일을 한 번에 업로드
- **처리 시간**: 파일 크기 및 복잡성에 따라 다름

## 업로드 프로세스

### **1단계: 기술 자료 선택**
- 기존 지식 기반을 선택하거나 새 지식 기반을 만듭니다.
- 쉽게 식별할 수 있도록 지식 기반에 이름을 지정하세요.

### **2단계: 문서 업로드**
- **드래그 앤 드롭**: 파일을 업로드 영역으로 드래그하기만 하면 됩니다.
- **파일 브라우저**: 파일을 탐색하고 선택하려면 클릭하세요.
- **일괄 선택**: 여러 파일을 한 번에 선택
- **진행 상황 추적**: 업로드 진행 상황을 실시간으로 확인하세요.

### **3단계: 처리 상태**
- **업로드 확인**: 파일이 성공적으로 업로드되었습니다.
- **처리 표시**: 문서가 처리되는 모습을 지켜보세요.

## 당신이 할 수 있는 일

### **문서 관리**
- **문서 업로드**: 기술 자료에 파일을 추가합니다.
- **업로드된 파일 보기**: 지식 베이스의 모든 문서를 확인하세요.

### **지식 기반 조직**
- **다중 기반 생성**: 주제 또는 프로젝트별로 문서를 정리합니다.
- **베이스 이름 지정**: 지식 베이스에 의미 있는 이름을 지정하세요.

## 모범 사례

### **서류 준비**
- 고품질의 가독성 높은 문서를 사용하세요.
- 텍스트가 명확하고 형식이 올바른지 확인하세요.
- 불필요한 서식이나 이미지를 제거합니다.
- 설명이 포함된 파일 이름을 사용하세요.

### **조직**
- 동일한 지식베이스에 관련 문서를 그룹화
- 일관된 명명 규칙을 사용하세요.
- 다양한 프로젝트에 대한 별도의 지식 기반 생성
- 오래된 문서를 정기적으로 검토하고 정리합니다.

### **업로드 팁**
- 효율성을 위해 문서를 일괄 업로드
- 대용량 파일 처리 현황 모니터링
- 빠른 처리를 위해 파일 크기를 10MB 미만으로 유지하세요.

## 일반적인 문제

| 이슈 | 솔루션 |
|-------|----------|
| 파일이 너무 큼 | 더 작은 파일로 분할하거나 압축 |
| 처리 실패 | 파일 형식을 확인하고 다시 시도하세요 |
| 업로드가 중단됨 | 페이지를 새로고침하고 다시 시도하세요 |

## 시작하기

1. **지식 베이스 생성**: 새로운 지식 베이스를 생성하는 것부터 시작하세요.
2. **문서 업로드**: 첫 번째 문서를 추가하세요.
3. **처리 대기**: 시스템이 파일을 처리하도록 합니다.
4. **채팅 시작**: 대화에서 지식 기반을 활용하세요
