# 원격 엔드포인트

원격 엔드포인트를 사용하면 AI 게이트웨이 제어를 통해 외부 또는 자체 호스팅 모델 서버를 SecureAI에 연결할 수 있습니다.

이는 조직이 자체 모델 인프라를 실행하고 여전히 중앙 집중식 보안 거버넌스를 원하는 경우에 유용합니다.

## 구성 위치

**관리자 → AI 게이트웨이 → 원격 엔드포인트**로 이동합니다.

## 등록 옵션

- **빠른 설치**: 단일 명령 설정 흐름을 생성하는 안내 마법사입니다.
- **수동 등록**:
  - **JSON 붙여넣기**
  - **수동 입력** 필드

## 연결 모드

- **역방향 연결**: 대부분의 배포에 권장됩니다. 아웃바운드 연결, 열려 있는 인바운드 포트가 없습니다.
- **Cloudflare Tunnel**: 터널 토큰과 호스트 이름을 사용한 제로 트러스트 연결.

## 일일 운영

각 엔드포인트에 대해 관리자는 다음을 수행할 수 있습니다.

- **상태 점검** 실행
- **mTLS 확인** 실행
- 엔드포인트 세부 정보 검사(지역, 지문, 모델, 마지막 확인)
- 폐기 시 엔드포인트 제거

## 제안된 온보딩 흐름

1. **빠른 설치**로 시작합니다.
2. 연결 모드를 선택합니다.
3. 필요한 모델을 선택하세요.
4. 등록을 완료하세요.
5. 상태 확인을 실행하고 mTLS를 확인합니다.
6. 5~10분 후에도 엔드포인트가 정상 상태로 유지되는지 확인합니다.

## 문제 해결 체크리스트

- 엔드포인트에 연결할 수 없음: 연결 모드 및 호스트 이름 값을 확인하세요.
- TLS는 통과했지만 비정상: 원격 게이트웨이/모델 서비스 상태를 확인하세요.
- 연결되지 않음: 원격 서비스가 실행 중이고 등록이 유효한지 확인하세요.

## 모범 사례

- 아키텍처에 터널 모드가 필요한 경우가 아니면 역방향 연결을 선호합니다.
- 조직/팀별로 엔드포인트 소유권을 명확하게 유지하세요.
- 정책이나 키 변경 후 엔드포인트 상태를 다시 확인하세요.
