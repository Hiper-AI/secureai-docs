# 클라우드 센서

**클라우드 센서**(관리자 → 에이전트 레지스트리 → **클라우드**)는 연결된 클라우드 AI 플랫폼(**Azure AI Foundry, AWS Bedrock, GCP Vertex AI, OpenAI Platform 및 Anthropic Console**) 내에서 검색된 에이전트, 모델 및 배포의 인벤토리입니다. 읽기 전용입니다. [통합](/ko/integrations/cloud/overview)에서 커넥터를 구성하면 Cloud Sensor가 발견한 내용을 표시합니다.

## KPI

| KPI | 의미 |
|------|---------|
| **연결된 제공업체** | 얼마나 많은 클라우드 제공업체가 구성되고 연결되어 있는지입니다. |
| **발견된 에이전트** | 현재 공급자 전체에 표시되는 총 에이전트/모델입니다. |
| **활성 클라우드 에이전트** | 에이전트가 최신 검색에 계속 존재합니다. |
| **자동 퇴직** | 최근 검색으로 제거된 에이전트(공급자에서 사라졌습니다). |

각 KPI에는 동기화 기록을 기반으로 구축된 30일 스파크라인이 포함됩니다.

## 인벤토리 테이블

| 칼럼 | 설명 |
|---------|-------------|
| **에이전트** | 에이전트/모델 이름을 발견했습니다. |
| **공급자** | Azure / AWS / GCP / OpenAI / Anthropic. |
| **작업공간/배포** | 공급자의 위치. |
| **모델** | 기본 모델. |
| **상태** | `observed`, `active` 또는 `retired`(검색에 의해 자동 종료되는 경우 `· auto` 접미사 포함) |
| **마지막 발견** | 마지막으로 봤을 때. |

공급자, 상태 또는 자유 텍스트 검색으로 필터링합니다. 보이는 행을 CSV로 내보냅니다.

## 동기화 중

단일 공급자에 대해 **동기화**를 실행하거나 **모두 동기화**를 실행하세요. 각 공급자는 **Insights** 대화 상자(해당 공급자와 관련된 사용량, 비용, 거버넌스 세부 정보)도 표시합니다. 커넥터 자격 증명 및 설정은 **관리 → 통합 → 클라우드**에 있습니다. 이 탭은 해당 탭으로 연결되며 빈 상태는 그곳을 가리킵니다.
