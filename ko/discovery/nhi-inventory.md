# NHI 재고

**NHI 인벤토리**(관리자 → 에이전트 레지스트리 → **비인간 ID**)는 AI 뒤에 있는 시스템 자격 증명, 즉 에이전트, MCP 서버 및 워크로드가 사용하는 API 키, 서비스 계정 및 BYOK 키의 인벤토리입니다. 모든 [클라우드 AI 제공업체](/ko/en/integrations/cloud/overview) 커넥터에서 발견한 ID를 롤업하고 위험 점수를 매기고 이를 차단하거나 취소할 수 있는 제어 기능을 제공합니다.

## 각 아이덴티티가 보여주는 것

- **공급자**(SecureAI/OpenAI/Anthropic/Azure/GCP/AWS) 및 **유형**(에이전트/mcp/워크로드).
- 기여 요인이 포함된 **위험 점수**(0~100)(아래 참조).
- **SMLTP 판정** 칩(차단/시행/모니터링) 및 수신 횟수입니다.
- **사용자**, **마지막 사용**(유휴 일수), **순환** 및 **만료 카운트다운**.
- **상태**: 정상/치료/중요.

## 제어 수준

신원에 대해 얼마나 *할 수* 있는지는 신원이 발견된 방법에 따라 다릅니다.

| 레벨 | 의미 | 가능한 조치 |
|-------|---------------|------|
| **관리됨** | SecureAI에서 발급한(비클라우드) ID입니다. | 게이트웨이에서 **차단/차단 해제** — 해당 ID로 인증된 모든 요청을 거부하거나 복원하고 게이트웨이 취소 목록을 푸시합니다. |
| **취소 가능** | 클라우드에서 검색되고** 소스에서 시행 가능합니다. | **취소** — 자물쇠("candadito"): **제공자에서** 키를 삭제/비활성화합니다. 뒤집을 수 없는; ID를 차단/중요하게 표시합니다. |
| **모니터 전용** | 클라우드에서 검색되었지만 시행할 수는 없습니다. | 읽기 전용입니다. 휴면 상태만으로는 위험 수준으로 확대되지 않습니다(모니터링 전용 위험 요소가 약간 추가됨). |

### 취소 가능한 클라우드는 무엇인가요?

| 신원 유형 | 소스에서 취소 가능 | 모니터 전용 |
|---------------|---------|-------------|
| **API 키** | OpenAI, 인류학, GCP, Azure, AWS | — |
| **서비스 계정/BYOK 키** | 인류학, GCP, Azure | 오픈AI, AWS |

## 작업

| 액션 | 효과 |
|---------|---------|
| **차단 / 차단 해제** | 관리 ID의 SecureAI 키(게이트웨이 취소 목록)로 인증된 요청을 거부/복원합니다. |
| **취소** | 공급자에게 취소 가능한 신원을 끊습니다. 외부 ID를 사용하여 ID를 시행할 수 있어야 합니다. 그렇지 않으면 "소스에서 취소할 수 없음"을 반환합니다. |
| **표시가 회전됨** | 키가 순환되었음을 기록합니다. |
| **서명키 등록/교체** | ID에 대한 SET 서명 키를 관리합니다. |

## 위험 점수

거버넌스 스위퍼는 휴면/휴면 중요, 회전 기한 초과/회전 중요, 만료/곧 만료, 광범위한 범위, 소유자 없음, 재활성화됨 및 모니터링 전용을 포함한 요소로부터 종합 0~100 점수를 계산합니다. 이전에 휴면 상태였던 ID가 다시 활성화되면 경고가 발생합니다.
