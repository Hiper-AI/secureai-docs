# OpenAI プラットフォーム

OpenAI 組織を接続すると、SecureAI がプロジェクト、モデル、メンバー、API キー、サービス アカウントのインベントリを作成し、アクティビティを支出し、監査できるようになり、修復のために漏洩したキーや過剰な権限を持つキーを表面化できるようになります。

## SecureAI がインポートするもの

- **プロジェクト、モデル、メンバー、役割、およびグループ**
- **NHI** — API キーとサービス アカウント (取り消し可能 — [NHI インベントリ](/ja/discovery/nhi-inventory) を参照)
- **支出アラート、レート制限、証明書、およびデータ保持設定**
- **監査ログ**
- 過去 30 日間の **使用量と費用** (ユーザーごとの支出を含む)

## 前提条件

- OpenAI プラットフォームの **組織所有者** (または管理者)。
- **管理 API キー** (`sk-admin-…`)。組織全体のプロジェクト、メンバー、使用状況を読み取るには管理者キーが必要です。

## 認証情報

|フィールド |必須 |説明 |
|----------|----------|---------------|
| `adminApiKey` |はい |組織 **admin** キー、形式 `sk-admin-…`。保存時は暗号化されます。 |
| `projectApiKey` |いいえ | 1 つ以上のプロジェクト キー (1 行に 1 つ)。従来のアシスタント インベントリにのみ必要です。 |
| `organizationId` |いいえ |あなたの `org-…` ID;キーが複数の組織にまたがる場合に曖昧さを解消します。 |

### 管理キーを入手する場所

1. [OpenAI Platform](https://platform.openai.com/) に組織所有者としてサインインします。
2. **[設定] → [組織] → [管理者キー]** に移動します。
3. 新しい管理キーを作成し、コピーします (1 回のみ表示)。

## 接続する

1. **「管理」→「統合」→「クラウド」→「OpenAI プラットフォーム」→「接続」**
2. 管理者 API キー (およびオプションのフィールド) を貼り付けます。
3. **テスト**し、**保存**します。
4. **同期**。

## 確認する

最初の同期後、[Cloud Sensors](/ja/discovery/cloud-sensors) を開いて検出されたモデル/アシスタントを確認し、[NHI Inventory](/ja/discovery/nhi-inventory) を開いてキーとサービス アカウントを確認します。プロバイダーごとの **インサイト** には、使用状況、コスト、ユーザーごとの支出が表示されます。

## 失効

OpenAI API キーは [NHI Inventory](/ja/discovery/nhi-inventory) から **取り消し可能**: SecureAI はソースでキーを無効にすることができます。 (サービス アカウントの場合、OpenAI ID はモニター専用です。)
