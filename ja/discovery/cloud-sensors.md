# クラウドセンサー

**クラウド センサー** (管理者 → エージェント レジストリ → **クラウド**) は、接続されたクラウド AI プラットフォーム (**Azure AI Foundry、AWS Bedrock、GCP Vertex AI、OpenAI Platform、Anthropic Console**) 内で検出されるエージェント、モデル、デプロイメントのインベントリです。これは読み取り専用です。[Integrations](/ja/en/integrations/cloud/overview) でコネクタを設定すると、Cloud Sensors が検出した内容を表示します。

## KPI

| KPI |意味 |
|-----|----------|
| **接続されたプロバイダー** |構成および接続されているクラウド プロバイダーの数。 |
| **検出されたエージェント** |現在プロバイダー全体で表示されているエージェント/モデルの合計。 |
| **アクティブなクラウド エージェント** |最新の発見ではエージェントがまだ存在しています。 |
| **自動リタイア** |最近の発見によりエージェントが削除されました (プロバイダーから消えました)。 |

各 KPI には、同期履歴から構築された 30 日間のスパークラインが含まれます。

## 在庫テーブル

|コラム |説明 |
|----------|---------------|
| **エージェント** |検出されたエージェント/モデル名。 |
| **プロバイダー** | Azure / AWS / GCP / OpenAI / Anthropic。 |
| **ワークスペース/展開** |プロバイダー上のどこに存在するか。 |
| **モデル** |基礎となるモデル。 |
| **ステータス** | `observed`、`active`、または `retired` (検出によって自動リタイアされる場合は `· auto` サフィックスが付きます)。 |
| **最後の発見** |最後に見たとき。 |

プロバイダー、ステータス、またはフリーテキスト検索でフィルターします。表示されている行を CSV にエクスポートします。

## 同期中

単一プロバイダーに対して **同期** を実行するか、**すべて同期** を実行します。各プロバイダーは、**インサイト** ダイアログ (そのプロバイダーに固有の使用量、コスト、ガバナンスの詳細) も公開します。コネクタの認証情報と設定は **[管理] → [統合] → [クラウド]** にあります。このタブはそこにリンクしており、空の状態でそこを指します。
