# 国民健康保険の在庫

**NHI インベントリ** (管理者 → エージェント レジストリ → **非人間 ID**) は、AI の背後にあるマシン認証情報のインベントリです。つまり、エージェント、MCP サーバー、およびワークロードが使用する API キー、サービス アカウント、BYOK キーです。すべての [Cloud AI Provider](/ja/en/integrations/cloud/overview) コネクタによって検出された ID をロールアップし、そのリスクをスコアリングして、それらをブロックまたは取り消すための制御を提供します。

## それぞれのアイデンティティが示すもの

- **プロバイダー** (SecureAI / OpenAI / Anthropic / Azure / GCP / AWS) および **タイプ** (エージェント / mcp / ワークロード)。
- **リスク スコア** (0 ～ 100) と要因 (以下を参照)。
- **SMLTP 判定** チップ (ブロック/強制/監視) と受信数。
- **使用者**、**最終使用日** (アイドル日)、**ローテーション**、**有効期限カウントダウン**。
- **ステータス**: 正常/修復/重大。

## 制御レベル

アイデンティティに対してどの程度「できる」かは、そのアイデンティティがどのように発見されたかによって異なります。

|レベル |意味 |利用可能なアクション |
|------|------|------|
| **管理** | SecureAI が発行した (非クラウド) ID。 |ゲートウェイでの **ブロック/ブロック解除** — その ID によって認証されたリクエストを拒否または復元し、ゲートウェイ失効リストをプッシュします。 |
| **取り消し可能** |クラウドで検出され、** ソースで強制可能。 | **取り消し** — 南京錠 (「candadito」): **プロバイダー**でキーを削除/無効にします。不可逆; ID をブロック/クリティカルとしてマークします。 |
| **モニターのみ** |クラウドで検出されましたが、強制力はありません。 |読み取り専用。休止状態だけでは、それが重大な状態にまでエスカレートすることはありません (監視のみの小さなリスク要因が追加されます)。 |

### どのクラウドが取り消し可能ですか

| ID タイプ |ソースで取り消し可能 |モニターのみ |
|--------------|---------------------|--------------|
| **API キー** | OpenAI、Anthropic、GCP、Azure、AWS | — |
| **サービス アカウント/BYOK キー** | Anthropic、GCP、Azure | OpenAI、AWS |

## アクション

|アクション |効果 |
|----------|----------|
| **ブロック / ブロック解除** |マネージド ID の SecureAI キー (ゲートウェイ失効リスト) によって認証されたリクエストを拒否/復元します。 |
| **取り消し** |プロバイダーで取り消し可能な ID を切断します。 ID が外部 ID で強制可能である必要があります。それ以外の場合は、「ソースでは取り消せません」を返します。 |
| **マークが回転しました** |キーがローテーションされたことを記録します。 |
| **署名キーの登録/ローテーション** | ID の SET 署名キーを管理します。 |

## リスクスコアリング

ガバナンス スイーパーは、休止中 / 休止中クリティカル、ローテーション期限切れ / ローテーション クリティカル、期限切れ / もうすぐ期限切れ、広範なスコープ、所有者なし、再アクティブ化、およびモニターのみなどの要素から 0 ～ 100 の複合スコアを計算します。以前に休止状態だった ID を再アクティブ化すると、アラートが生成されます。
