# モデル

SecureAIで利用可能なモデル。

SecureAI は、すべての主要プロバイダーの最新の AI モデルへのアクセスを提供し、特定のニーズに最適なツールを提供します。

API キーのモデルの可用性をリアルタイムで取得するには、外部エンドポイント `GET /api/external/models` を使用します。

## バケットのタイプ

### 標準バケット
- **使用方法**: 日常業務や一般的な会話
- **コスト**: 通常の使用ではよりコスト効率が高くなります。
- **速度**: より高速な応答を実現するために最適化されています。
- **最適な用途**: 簡単な質問、単純なタスク、日常的な作業

### プレミアムバケット
- **使用方法**: 複雑な推論と高度な分析
- **コスト**: 機能を強化するとコストが高くなります
- **スピード**: 時間がかかる場合がありますが、優れた結果が得られます
- **最適な用途**: 複雑な問題解決、詳細な分析、特殊なタスク

## モデル選択ガイド

### 複雑な推論の場合
- **anthropic/claude-opus-4.6** - 深い分析タスクに最適
- **openai/gpt-5.2** - 強力な推論と合成
- **google/gemini-3.1-pro-preview** - 高度な推論機能

### 迅速な開発のために
- **openai/gpt-5-nano** - 簡単なタスクに対する素早い応答
- **google/gemini-3-flash-preview** - 優れた速度とコストのバランス
- **x-ai/grok-3-mini** - 高速なイテレーションとプロトタイピング

### コード生成の場合
- **openai/gpt-5.3-codex** - 特化したコーディング ワークフロー
- **qwen/qwen3-coder-next** - 強力なコード生成と編集
- **deepseek/deepseek-r1** - 推論を重視したコード分析

### 大規模なコンテキストの場合
- **openai/gpt-5.1** - 大規模なコンテキスト分析タスク
- **anthropic/claude-sonnet-4.6** - 強力な長い形式のコンテキスト処理
- **google/gemini-3.1-pro-preview** - 包括的なドキュメント分析

## モデルの機能

### コンテキストウィンドウ
- **標準コンテキスト**: ほとんどのモデルは 16,000 ～ 200,000 トークンをサポートします
- **拡張コンテキスト**: 一部のモデルは無制限のコンテキストをサポートします
- **最適化された処理**: モデルは特定のユースケースに合わせて最適化されます

### 機能の特長
- **🧠 標準 AI**: テキスト生成、推論、コーディング
- **📊 分析**: データの分析と解釈
- **💻 コード**: 特殊なコードの生成とレビュー
- **🎯 特化**: タスク固有の最適化

## 自動選択

SecureAI には、特定のタスクに最適なモデルを自動的に選択し、以下を最適化する **自動選択** 機能が含まれています。
- **タスクの複雑さ**: モデルの機能をニーズに合わせます
- **応答速度**: 速度と品質のバランスを保ちます
- **コスト効率**: 予算に合わせて最適化します。
- **コンテキスト要件**: 適切なコンテキスト ウィンドウを持つモデルを選択します
