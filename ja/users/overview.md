# ユーザーとアクセスの管理

SecureAI は、エンタープライズ グレードのユーザー管理、ロールベースのアクセス制御 (RBAC)、権限階層、ライセンス割り当てを提供します。

---

## システムの役割

SecureAI には、プラットフォーム アクセスを管理するためのシステム ロールが組み込まれています。

|役割 |アクセスレベル |説明 |
|---|---|---|
| **管理者** |フルコントロール |完全な管理権限: ユーザーの管理、カスタム ロールの作成、SMLTP/AI ゲートウェイ ポリシーの構成、ログの表示、および SSO の構成。 |
| **ユーザー** |標準 |通常のユーザー アクセス: AI モデルとのチャット、個人インデックスの作成と管理、ドキュメントのアップロード。 |
| **グローバルリーダー** |読み取り専用 |標準ユーザーと同じ機能に加え、管理パネルとシステムステータスに対する読み取り専用の可視性を備えています。設定を変更できません。 |

### カスタムロールと詳細な権限
管理者は、特定のモジュールにわたって、カスタマイズされた権限レベル (**なし**、**読者**、**管理者**) を持つカスタム ロールを作成できます。
- **ユーザーとグループの管理**: ユーザーの作成、編集、グループの割り当て。
- **インデックス管理**: ドキュメントのアップロード、インデックスの作成、インデックスのトレーニング。
- **セキュリティと SMLTP**: セキュリティ ポリシー、インシデント対応、監査検証。
- **統合と AI ゲートウェイ**: クラウド プロバイダー、API キー、エンドポイントを接続します。

---

## ライセンス管理

ユーザー アカウントは、組織のライセンス層に基づいてプロビジョニングされます。

|階層 |含まれる機能 |
|---|---|
| **ウルトラ** |完全なプラットフォーム機能、無制限のインデックス、優先モデルのスループット、カスタム SMLTP コンプライアンス ポリシー、専用サポート。 |
| **成長** |チーム コラボレーション ツール、グループ インデックス、標準 SMLTP セキュリティ ポリシー、標準サポート。 |
| **必須** |コアチャットインターフェイス、個人インデックス、基本モデルアクセス、コミュニティサポート。 |

---

## 一般的な管理タスク

- **ユーザーの作成**: **管理者に移動しますか?ユーザー?ユーザーを作成します**。電子メール、役割、ライセンス層を設定します。
- **グループに割り当てる**: **管理者に移動しますか?グループ** では、共有グループ インデックスを使用してユーザーを協力的なチームに編成します。
- **SSO の構成**: **認証** 設定でエンタープライズ ID プロバイダー (Google Workspace または Microsoft Entra ID) に接続します。
