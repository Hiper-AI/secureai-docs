# データ保護

データ保護は、AI とのやり取り中のビジネス機密情報や個人を特定できる情報 (PII) の偶発的または悪意のある漏洩を防ぎます。

---

## コア保護機能

### 1. DLP 管理 (ビジネスデータ損失防止)
プロンプト、アップロードされたファイル、およびモデル応答内の独自のビジネス資産を保護します。
- **API キーと認証情報**: AWS キー、OpenAI トークン、パスワード、プライベート証明書の漏洩を防ぎます。
- **ソース コードとアーキテクチャ**: 内部リポジトリとコード スニペットを検出します。
- **契約と財務**: 機密の契約草案と財務データを特定します。

### 2. PII 編集 (プライバシーとコンプライアンス)
GDPR、HIPAA、CCPA の基準を満たすために、個人識別情報を自動的に検出してマスクします。
- **識別子**: 名前、電子メール アドレス、電話番号、国民 ID (SSN、DNI、パスポート番号)、クレジット カード。
- **秘匿化モード**:
  - **マスク**: 機密文字列を難読化します (例: user@*****.com、****-****-****-1234)。
  - **削除**: 機密テキストを完全に削除します。
  - **トークン化 / ハッシュ**: 内部処理のために機密データを決定的な仮名に置き換えます。

### 3. セマンティック検証者
疑わしいテキストが SecureAI テナントによって生成されたかどうかを判断することで、セキュリティおよび法的調査を支援します。
- **信頼レベル**: *検証済み*、*一致の可能性*、*あいまい*、*一致なし*。
- **使用方法**: **管理者に移動しますか?データ保護 ? Semantic Verifier** に移動し、テキスト スニペットを貼り付けて、起源の確率を分析します。

---

## 構成とセットアップ

1. **グローバル設定**: **管理者に移動しますか?データ保護** により、入力、出力、添付ファイルのリアルタイム スキャンが可能になります。
2. **テンプレートとカスタム ルール**: 地域/業界のスターター テンプレートをロードするか、カスタマイズされた正規表現パターンを追加します。
3. **シミュレーション モード**: 運用環境でポリシーを適用する前に、サンプル データセットに対してポリシーをテストします。
4. **インシデントの監視**: データ保護インシデント ログで編集とブロックの指標を確認します。
